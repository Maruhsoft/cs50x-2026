# Problem Set 1 — C

## Overview

Problem Set 1 introduces the C programming language.

Topics include:

- Variables
- Data types
- Functions
- Conditionals
- Loops
- User input
- Compilation
- Basic debugging

## Problems

### Hello, World

Write a basic C program that prints a greeting.

### Hello, It's Me

Practice formatted output and user interaction.

### Mario — Less Comfortable

Create a right-aligned pyramid using loops.

### Mario — More Comfortable

Create a more complex pyramid using loops.

### Cash

Implement a program that determines the minimum number of coins required for a given amount.

### Credit

Determine the validity and card type of a credit-card number using an algorithm based on its digits.

## Recommended Workflow

1. Read the official specification for each problem.
2. Understand the required input.
3. Determine the required output.
4. Identify constraints and edge cases.
5. Write pseudocode.
6. Implement the solution in C.
7. Compile with `make`.
8. Test manually.
9. Run the appropriate `check50` command.
10. Fix failures.
11. Run `check50` again.
12. Submit using `submit50`.
13. Commit the completed work to Git.
14. Push to GitHub.
