# Problem Set 6 — Python

## Overview

Problem Set 6 revisits several earlier programming problems using Python.

## Problems

### Hello

Implement a basic Python program.

### Mario — Less Comfortable

Create the required pyramid using Python.

### Mario — More Comfortable

Create the more complex pyramid using Python.

### Cash

Calculate the minimum number of coins required.

### Credit

Validate and identify credit-card numbers.

### Readability

Calculate the reading grade level of supplied text.

### DNA

Identify a person from DNA sequence data.

## Objectives

- Learn Python syntax.
- Use Python variables and types.
- Work with strings.
- Use lists and dictionaries.
- Define functions.
- Process files.
- Handle command-line arguments.
- Translate algorithmic thinking from C to Python.

## Recommended Workflow

1. Read the specification.
2. Compare the problem with its C version where applicable.
3. Identify Python-specific tools.
4. Write pseudocode.
5. Implement.
6. Run the program with Python.
7. Test manually.
8. Run `check50`.
9. Debug.
10. Submit with `submit50`.
11. Commit and push.
