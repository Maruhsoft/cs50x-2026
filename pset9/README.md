# Problem Set 9 — Flask

## Overview

Problem Set 9 introduces server-side web application development with Flask.

The work combines:

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQL
- HTTP
- Templates
- Forms
- Sessions

## Problems

### Birthdays

Build a web application that allows users to record and view birthdays using a database.

### Finance

Build a simulated stock-trading web application with user accounts, portfolios, transactions, and database-backed data.

## Objectives

- Understand Flask routes.
- Render templates.
- Process forms.
- Work with sessions.
- Use SQL from a web application.
- Validate user input.
- Maintain application state.
- Separate application logic from presentation.

## Recommended Workflow

1. Read the specification completely.
2. Study the supplied application structure.
3. Understand the routes.
4. Understand the database schema.
5. Run the starter application.
6. Test existing functionality.
7. Implement one feature at a time.
8. Test each route manually.
9. Test invalid input.
10. Test database behavior.
11. Run `check50`.
12. Debug.
13. Submit with `submit50`.
14. Commit and push.
