# Problem Set 4 — Memory

## Overview

Problem Set 4 introduces memory-related concepts in C.

Topics include:

- Pointers
- Memory addresses
- Dynamic memory
- Files
- Binary data
- Image processing
- Raw byte manipulation

## Problems

### Volume

Modify the volume of a WAV audio file by applying a scaling factor to its samples.

### Filter — Less Comfortable

Apply image filters to bitmap images.

### Filter — More Comfortable

Implement additional image-processing filters.

### Recover

Recover JPEG images from a forensic memory-card image.

## Objectives

- Understand pointers.
- Access memory through addresses.
- Work with structures.
- Read and write binary files.
- Manipulate raw data.
- Understand file signatures.
- Manage memory safely.

## Recommended Workflow

1. Read the specification.
2. Study the supplied starter code.
3. Understand each data structure.
4. Determine how bytes are represented.
5. Trace the program with small examples.
6. Implement incrementally.
7. Compile with `make`.
8. Test carefully.
9. Use `check50`.
10. Investigate memory-related failures.
11. Submit with `submit50`.
12. Commit and push.
