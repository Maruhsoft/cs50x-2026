# Problem Set 8 — HTML, CSS, JavaScript

## Overview

Problem Set 8 introduces client-side web development.

Topics include:

- HTML
- CSS
- JavaScript
- DOM manipulation
- Events
- Forms
- Web-page structure
- Browser behavior

## Problems

### Trivia

Create an interactive trivia page using HTML, CSS, and JavaScript.

### Homepage

Create a personal homepage demonstrating web-development concepts.

## Objectives

- Structure pages with HTML.
- Style pages with CSS.
- Add behavior with JavaScript.
- Respond to user events.
- Manipulate the DOM.
- Build accessible and usable interfaces.

## Recommended Workflow

1. Read the specification.
2. Plan the page structure.
3. Build the HTML.
4. Add CSS.
5. Add JavaScript behavior.
6. Test in a browser.
7. Inspect the DOM and console.
8. Test different interactions.
9. Run `check50`.
10. Fix issues.
11. Submit with `submit50`.
12. Commit and push.
