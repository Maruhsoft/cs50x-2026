# Problem Set 7 — SQL

## Overview

Problem Set 7 introduces relational databases and SQL.

## Problems

### Songs

Query a database containing information about songs and artists.

### Movies

Query a database containing information about movies, ratings, and people.

### Fiftyville

Investigate a fictional crime by querying a relational database and connecting information across tables.

## Objectives

- Understand relational databases.
- Write SQL queries.
- Filter records.
- Sort results.
- Aggregate data.
- Join tables.
- Use subqueries.
- Reason about relationships between records.

## Recommended Workflow

1. Read the specification.
2. Inspect the database schema.
3. Identify relevant tables.
4. Identify relevant columns.
5. Build queries incrementally.
6. Test each query.
7. Compare results with the question.
8. Use joins where necessary.
9. Use aggregation where necessary.
10. Document useful discoveries.
11. Run `check50`.
12. Submit with `submit50`.
13. Commit and push.
