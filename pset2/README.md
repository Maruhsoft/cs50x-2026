# Problem Set 2 — Arrays

## Overview

Problem Set 2 develops familiarity with arrays, strings, and character manipulation in C.

## Problems

### Scrabble

Calculate the score of words according to a predefined letter-scoring system.

### Readability

Calculate the approximate reading grade level of a text using counts of letters, words, and sentences.

### Caesar

Encrypt text using a Caesar cipher and a supplied key.

### Substitution

Encrypt text using a substitution cipher and a supplied 26-character key.

## Objectives

- Work with arrays.
- Process strings character by character.
- Use ASCII values.
- Convert between uppercase and lowercase.
- Validate command-line arguments.
- Manipulate characters.
- Build reusable functions.
- Understand algorithmic transformations.

## Recommended Workflow

1. Read the specification.
2. Identify the required inputs.
3. Determine the transformation or calculation.
4. Design the algorithm.
5. Write pseudocode.
6. Implement incrementally.
7. Compile with `make`.
8. Test normal cases.
9. Test boundary cases.
10. Test invalid input.
11. Run `check50`.
12. Fix failures.
13. Submit with `submit50`.
14. Commit and push the work.
