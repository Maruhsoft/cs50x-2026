# Problem Set 5 — Data Structures

## Overview

Problem Set 5 focuses on data structures, dynamic memory allocation, and efficient lookup.

## Problems

### Inheritance

Simulate the inheritance of blood-type alleles through multiple generations.

### Speller

Implement a spell checker using a dictionary and an appropriate data structure.

## Objectives

- Understand structs.
- Allocate and free memory.
- Work with linked structures.
- Understand hash tables.
- Analyze lookup performance.
- Prevent memory leaks.
- Design efficient data structures.

## Recommended Workflow

1. Read the complete specification.
2. Understand the starter code.
3. Identify supplied structures and functions.
4. Determine required memory ownership.
5. Design the data structure.
6. Implement carefully.
7. Compile with `make`.
8. Test functionality.
9. Test memory behavior.
10. Use `check50`.
11. Use memory-analysis tools when appropriate.
12. Submit with `submit50`.
13. Commit and push.
