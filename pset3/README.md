# Problem Set 3 — Algorithms

## Overview

Problem Set 3 focuses on algorithms, searching, sorting, and computational efficiency.

## Problems

### Sort

Analyze and identify sorting algorithms by their behavior and performance.

### Plurality

Implement an election system in which each voter selects one candidate and the candidate with the most votes wins.

### Runoff

Implement ranked-choice voting using successive rounds and elimination.

### Tideman

Implement the Tideman ranked-choice voting system using pairwise preferences and a directed graph.

## Objectives

- Analyze algorithms.
- Understand asymptotic performance.
- Work with arrays and structures.
- Implement searching and sorting concepts.
- Process elections.
- Work with graphs.
- Detect cycles.

## Recommended Workflow

1. Understand the algorithm required.
2. Identify the supplied data structures.
3. Trace sample input manually.
4. Write pseudocode.
5. Implement one function at a time.
6. Compile frequently.
7. Test simple cases.
8. Test edge cases.
9. Use `check50`.
10. Debug failures systematically.
11. Submit using `submit50`.
12. Commit and push.
