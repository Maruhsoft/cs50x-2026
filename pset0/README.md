# Problem Set 0 — Scratch

## Overview

Problem Set 0 introduces programming through Scratch, a block-based programming environment.

## Objectives

- Understand algorithms and program structure.
- Use events and sequencing.
- Work with variables.
- Use conditionals and loops.
- Create custom blocks.
- Develop a complete interactive program.

## Assignment

### Starting from Scratch

Create an original Scratch project demonstrating programming concepts learned in the course.

## Recommended Workflow

1. Read the official specification.
2. Choose a project idea.
3. Identify the inputs, outputs, and interactions.
4. Design the program flow.
5. Implement the project in Scratch.
6. Test every interaction.
7. Check edge cases.
8. Submit using the required CS50 submission process.

## Testing Checklist

- [ ] Project starts correctly.
- [ ] User interaction works.
- [ ] Variables behave correctly.
- [ ] Loops terminate as intended.
- [ ] Conditions produce the expected behavior.
- [ ] No obvious bugs remain.
- [ ] Project meets the specification.
- [ ] `check50` completed where applicable.
- [ ] `submit50` completed.
